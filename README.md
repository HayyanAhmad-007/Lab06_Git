# Number-to-Words Converter


\## Project Title

Number to Words Converter Using C++



\## Purpose

This program converts the digits of an entered number into English words using a switch statement. It also counts the total number of digits.



\## How to Run the Program

1\. Open `tut.cpp` in VS Code.

2\. Compile the program using a C++ compiler.

3\. Run the executable file.

4\. Enter a positive integer.



\## Example Input

123



\## Example Output

One Two Three



The number of digits said were: 3
